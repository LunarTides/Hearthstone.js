One of Hearthstone.js's selling points is the creation and distributions of `resources` like cards.

It's recommended to be atleast somewhat familiar with TypeScript when making resources,
but you might be fine with even a redumentary understanding of programming concepts.
*(If statements, for loops, etc...)*

In order to create resources, you need to select `Universe > [emergence]` from the hub. Here you can choose to create, edit, or delete resources.

Once you have made a certain amount of resources, you can create a [pack](../packs/introduction/), and upload it to the [registry](../packs/registry/).
